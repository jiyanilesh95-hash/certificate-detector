# QUICK START GUIDE

## 🚀 Super Easy - 3 Steps!

### Step 1: Download Project
1. Go to: https://github.com/jiyanilesh95-hash/certificate-detector
2. Click green **"Code"** button
3. Click **"Download ZIP"**
4. Extract the ZIP file

### Step 2: Run the Script

**Windows:**
- Double-click `run_windows.bat`
- Wait for setup to complete

**Mac/Linux:**
- Open Terminal in the folder
- Copy & paste: `chmod +x run_mac_linux.sh && ./run_mac_linux.sh`
- Press Enter

### Step 3: Open Website
1. Wait for the message: `🚀 Server starting...`
2. Open your browser
3. Go to: `http://localhost:5000`
4. **Done!** 🎉

---

## 📸 What You'll See

1. **Purple website** with "Certificate Detector" title
2. **Upload button** to select certificate images
3. **Analyze button** to run detection
4. **Results** showing confidence score and analysis

---

## 📝 How to Use

1. Click **upload area** or drag certificate image
2. Click **"🔍 Analyze Certificate"**
3. Wait 2-3 seconds
4. See instant results! ✅

Press `Ctrl + C` in terminal
